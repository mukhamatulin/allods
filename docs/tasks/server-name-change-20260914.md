# Задача: выгрузка рейтингов для двух серверов

- Идентификатор: `server-name-change-20260914`
- Источник запроса: пользовательская задача без идентификатора Redmine
- Файл основной правки: `src/allods_hpi_to_xlsx.py`

## Контекст

Скрипт должен сохранять текущую выгрузку для сервера «Молодая Гвардия» и дополнительно формировать такую же выгрузку для сервера «Наследие Богов». В конфигурации рейтингов Allods Online этим серверам соответствуют идентификаторы `601` и `101`.

Для листов целей первый ник должен быть `Нулёвый`, второй ник пока остаётся пустым.

## Критерии приёмки

1. Запуск без параметров создаёт отдельный XLSX для каждого из двух серверов.
2. Для каждого сервера используется отдельный файл истории, чтобы сравнение запусков не смешивало данные серверов.
3. Явный параметр `--shard-id` позволяет сформировать один выбранный сервер.
4. Листы целей используют ники `Нулёвый` и пустую строку.
5. Автоматический запуск передаёт отдельные пути публикации для двух XLSX.
6. Исходный временный файл `~$allods_hpi_molodaya_gvardiya.xlsx` не изменяется и не включается в коммит.

## План

1. Ввести конфигурацию серверов и вынести формирование одного отчёта в переиспользуемую функцию.
2. Запускать формирование для двух серверов по умолчанию и сохранять отдельные состояния.
3. Обновить автоматический запуск и документацию с новыми именами файлов.
4. Выполнить синтаксическую, точечную и проектную проверки.

## TDD и проверка

Для небольшого изменения конфигурации и orchestration отдельный тестовый каркас в проекте отсутствует. Проверка будет выполнена через компиляцию Python, статическую проверку интерфейса и изолированный прогон с подменёнными сетевыми функциями.
