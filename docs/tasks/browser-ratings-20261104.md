# Восстановление официальной выгрузки рейтингов

## Контекст и границы

- Запрос: восстановить обычный и ежедневный запуск после HTTP 403 официального API.
- Уточнение: AllodsTop исключён из-за неактуальных данных.
- Источник остаётся https://allods.ru/api/rating; состав XLSX и публикация на Яндекс Диск сохраняются.
- Redmine id отсутствует; использован локальный идентификатор задачи.
- Режим: tracked. Ветка: codex/browser-ratings-20261104-1220.
- Имеющиеся пользовательские XLSX/JSON и временный файл Excel не входят в изменения.

## Причина и доказательства

- urllib получает HTTP 403, HTML с /bp_chl.js и требованием JavaScript.
- Обычная браузерная сессия возвращает JSON с HTTP 200.
- Отдельный Microsoft Edge через Playwright, headless=True, без сохранённого профиля и подмены параметров, получил 100 записей общего HPI.
- Официальный API помечает JSON как text/html; проверять нужно содержимое, а не только Content-Type.

## План

1. Добавить проверку клиента на локальном HTTP-сервере: JavaScript-проверка, сохранение сессии, ошибочные ответы и ограничение времени.
2. Добавить отдельный браузерный клиент и передать его сборщикам HPI, астрала и арены. Одна сессия на запуск, обязательное закрытие.
3. Обновить зависимости и инструкции запуска, проверить возврат кода ошибки из bat.
4. Запустить тесты, проверку синтаксиса, CLI и полный экспорт обоих серверов в отдельный каталог без публикации.
5. Проверить изменения и сделать локальный коммит. Push требует отдельного подтверждения согласно правилам harness.

## Критерии приёмки

- Официальные HPI, астрал и арена доступны при запуске без параметров и из ежедневного сценария.
- Все поля difficulty/time/achievement сохранены; листы отчёта не сокращены.
- Нет стороннего источника, обходного HTTP-загрузчика, сохранения cookie или подмены защиты браузера.
- Неуспешная проверка ограничена --timeout и завершается понятной ошибкой.
- Личная браузерная сессия и профиль пользователя не используются.

## Проверки и риски

- Проект не содержит Makefile, composer.json, pyproject или CI. Проверки: unittest, py_compile, CLI --help, живой экспорт.
- Для загрузки используется установленный Microsoft Edge и пакет Playwright в том же Python, который запускает bat.
- Если сайт потребует ручную CAPTCHA, полностью автоматический запуск не гарантируется. Её решение не реализуется.
- Проверки записывают XLSX и историю только в отдельный каталог; токен Яндекса не используется.
- Статус: реализовано; локальные проверки и живой экспорт прошли. Публикация и push не выполнялись.

## Реализация

- src/browser_ratings.py: изолированный headless Microsoft Edge; выполнение обычного JavaScript сайта; одна сессия на весь запуск, закрытие при ошибках и завершении.
- src/allods_hpi_to_xlsx.py: клиент передаётся сборщикам HPI, астрала и арены. Формирование отчёта и загрузчик Яндекса не менялись.
- JSON читается из исходного HTTP-ответа: API отдаёт Content-Type text/html, а чтение отрисованного текста изменяет символы `<` и `&`. Отдельный тест воспроизвёл и подтвердил исправление.
- run_daily.bat: рабочий каталог берётся из расположения bat, пути заключены в кавычки, аргументы передаются скрипту, возвращается код его завершения.
- requirements.txt и README.md: Playwright и требование установленного Edge, настройка Python для планировщика.
